# 赛程规划画布

入口为 /canvas-lab，访问需要登录。
独立赛程页面为 /canvas-lab/preview。
画布保存规划草稿，不记录真实比分。

本地入口：[打开画布](http://127.0.0.1:5010/canvas-lab)。
校园网入口：[打开画布](http://10.82.238.254:5010/canvas-lab)。
校园网访问取决于 WLAN 地址及防火墙规则。

## Stage、Wave、Session 与 Round

| 概念 | 用途 |
|---|---|
| stage | 画布框选的大分组，严格按阶段顺序执行 |
| wave | 验证自动生成的基本赛程单位 |
| session | 赛程页面的小分组，安排 wave 顺序和时段 |
| round | 瑞士轮及小组循环赛的一轮全部对阵，整体归入一个 wave |

同一 wave 不能跨直接 graph 或 stage。
wave 内不能存在人员冲突和结果先后需求。
编号在每个 graph 内统一生成。
不同子图可以各自显示 wave 1。
引用使用身份标识，不使用显示编号。

stage 1 全部结束后，stage 2 才能开始。
stage 不改变子图层级和连线边界。
每个 wave 显示全部前置需求。
跨图共享人员也会产生执行顺序。

瑞士轮的 round 暂时表示整轮配对占位。
循环赛的 round 包含规划对阵和休息名单。
比赛场数只作统计，不用于拆分基本调度单元。
画布不生成真实成绩。
单败和双败不使用 round 字段。

## 建图和分组

1. 从左侧组件库添加来源和比赛。
2. 点击输入和输出端口，建立图内连接。
3. 点击“框选模式”。
4. 在空白处拖出矩形，选择当前图的卡片。
5. 点击左侧 Subgraph 下方的“Stage · 分组所选”。
6. 已有归属时，加入顺序最低的 Stage。
7. 如果分组不符合预期，点击“撤销”。
8. 保存草稿。
9. 点击“验证保存版本”。
10. 查看右侧的验证批次和前置需求。

来源集合需要展开后才能连接 Match A/B。
Pool 输入按端口顺序拼接。
选择器和排序器不单独消耗 wave。
未加入阶段的真实比赛会收到诊断。

Ctrl/⌘ 点击可以增减多选。
Ctrl/⌘+G 可以封装同层卡片。
Ctrl/⌘+Shift+G 可以分组所选组件。
新增组件后，该组件成为当前选择。
旧 Stage 和组件选择会清除。
点击 Stage 分组或按快捷键即可分组。
Stage 编号由编号工具统一分配。
工具维护已用编号和最新编号。
新分组优先使用最小的可用编号。
保存草稿会保留最新编号。
封装与 stage 分组分别操作。
Stage 支持全部组件，包含来源和处理组件。
Ctrl/⌘ 点击 Stage 和组件，可混合多选。
分组时检查所选组件的阶段归属。
全部未分组时，新建 Stage 并加入组件。
只选同一 Stage 的成员且未选满时，拆成新 Stage。
选中 Stage 本身或选满成员时，复用原 Stage。
其他有归属的选择加入顺序最低的 Stage。
目标 Stage 的名称、顺序和原有成员保留。
跨阶段选择的组件移入目标 Stage。
选中的 Stage 也参与最低顺序判断。
操作后自动选中目标 Stage。
成员归并不要求转移确认。
分组结束后，自动删除 0 成员的 Stage。
编号工具释放这些 Stage 占用的编号。
最新编号保留历史最大值，释放的编号可复用。
选择 Subgraph 时，Stage 纳入内部全部组件。
成员列表用 Subgraph 代表内部组件。
展开子图后，内部组件的阶段归属保留。

点击阶段标题或左侧阶段列表，选中 Stage。
右侧属性显示名称、顺序和成员列表。
修改阶段名称和顺序后自动生效。
成员列表支持添加和移除全部组件类型。
选中 Stage 后，Delete 仅删除阶段。
删除 stage 保留比赛，并提示重新分组。
所有图编辑支持撤销和重做。
封装或展开后，验证重新计算 graph 归属。

## 参数与接口

普通点击卡片打开参数面板。
名称、选项、数量及显示设置修改后自动生效。
参赛席位和外部种子映射在离开输入框后生效。
保存草稿先结束当前字段编辑，再读取本地快照。
空数值和非法名称保留在输入框中，并阻止保存或切换项目。
名称是全部组件共用的可编辑属性。
坐标、稳定标识和图层归属保留在草稿中。
属性面板不显示这些内部字段。
拖动卡片修改坐标。
属性生效后，点击“保存草稿”持久化。
Pool 不再提供“输入顺序”属性编辑区，输入端口和既有拼接顺序仍保留。
展开器只读显示展开数量、来源集合数量、输出席位数及状态，不保存数量参数。
未知人数显示待解析；固定预设的规划容量与实际输入集合人数分别显示。
需要筛选席位时，先用选择器，再连接展开器。

瑞士轮默认显示人数、轮数，不新增胜场参数。
人数是计划容量，必须与连接集合人数一致。
阈值模式显示最大规划轮窗口，专用规则显示固定值。
规则版本、单场赛制、计分、同分顺序、配对和种子设置位于“高级规则”。
同分顺序使用中文列表，支持上移、下移及增删合法规则。
“逐轮覆盖”只显示已添加的轮次。
选择轮次后，点击“添加轮次覆盖”并修改 BO。
点击“移除”后，该轮恢复使用默认 BO。
排名输出采用完整排名，并列时需要裁定。
瑞士轮仍只预留整轮，真实配对待解析。

“小组赛”分类可添加小组循环赛，一个节点对应一个小组。
循环方式可选单循环或双循环，人数和轮数由输入集合推导。
预计场数只显示统计；预览按轮展示双方来源和休息名单。
session 安排整轮所属的 wave，时间和筛选同时适用于轮次。
“允许选手提交双方判负”只控制提交权限，不限制编辑员裁定。

Match 的“单场赛制”提供 BO1 和 BO3。
Match 位于“淘汰赛”分类，表示淘汰赛单场对决。
Match 固定产生唯一胜者和败者，不提供赛果列表。
平局和双方判负由瑞士轮或循环赛的规则处理。
Match 只保存当前单场赛制和可选条件，旧赛果、局数及批次字段不再接受。
Match 不配置时间，排期时间统一使用 session。
“取前 K 名”和“随机 K 名”为两个组件，分别固定选择方式。
开启“展示补集”后增加未选中集合输出，补集保留输入顺序。
关闭有连接的补集或缩容影响下游时，需要确认受影响连接。
随机 K 名使用固定随机数种子，保存重载后沿用同一次选择。
K 超限时，提示选择数量和输入数量；输入为空时明确显示 N=0。
Pool 按输入端口顺序拼接集合。
子图接口位于“高级边界设置”。

当前只接受 canvas 配置，旧格式编辑和迁移入口已移除。
每个画布保存最新图；版本号用于检测并发保存冲突。

输入端口在左侧，输出端口在右侧。
同时只选中 1 个端口，并显示描边。
点击空白或拖动背景保留选择和已有连线。
点击非法目标时，改为选中该目标，保留已有连线。
点击有效目标时，连接两端并清除端口选择。
再次点击已选端口时，断开该端口的连线并清除选择。
子图出口的断开操作保留子图内部连线。
类型不匹配、循环或跨图连接不报错。
网络或权限失败仍显示错误。
点击图中连线后，按 Delete 或点击“删除所选连接”。
连接表单已移除。
拖动标题移动卡片，拖动背景平移。
滚轮缩放，“适应全图”定位全部卡片。

参赛来源输出初始席位集合和初始种子。
逐席位端口保留已有连接。
Match 单方缺席时按轮空晋级处理。
Match 双方缺席时输出空席位。
轮空不占人员执行批次。
配置错误不会当作正常轮空。

悬空接口可以隐藏，但不会删除。
已经连接的接口保持可见。
子图收集内部全部开放输入和输出。
分组列表、选择列表和诊断摘要以子图为单位。
进入子图或展开诊断详情时，显示内部组件。
详细赛程使用内部比赛及瑞士轮、循环赛轮次。
删除接口或缩容时，先检查连接影响。

新图不提供手填 batch 或 wave 编号。
wave 由验证统一生成。
新增比赛后，需要加入阶段并重新验证。

## Session 排期

1. 打开顶部“打开赛程预览”。
2. 选择一个赛事项目。
3. 点击“新建 session”。
4. 选择待安排的 wave。
5. 调整 wave 顺序。
6. 填写开始和结束时间段。
7. 检查前置需求和时间诊断。
8. 点击“保存排期”。

时间使用含 UTC 偏移的 ISO 格式。
例如：2026-10-14T09:00:00+08:00。
结束时间必须晚于开始时间。
缺少时间可以保存草稿，但仍提示待确认。

同一 session 内，前置 wave 必须排在前面。
有跨 session 依赖时，时段不能重叠。
“预览依赖排序”先展示排序结果。
点击“应用依赖排序”后才改变本地列表。

wave 可以移除或移动到另一个 session。
同一 wave 不能重复安排。
未安排的 wave 显示在待排期列表。
排期按项目保存，并使用独立版本。

列表中的时间范围表示整个 session。
系统不把该范围当作每场比赛的开始时间。
缺少逐场时长时，时段容量仍待确认。

## 验证变化和失效修复

修改并保存图后，原验证产物失效。
重新验证可能改变 wave 成员和前置需求。
原 session 和绑定快照仍保留。

1. 在赛程页面读取排期版本。
2. 检查旧成员和旧前置需求。
3. 替换失效 wave，或移除旧引用。
4. 补充当前待安排的 wave。
5. 检查顺序和时间段。
6. 保存排期并绑定当前产物。

引用修复保留 session 名称和时间段。
存在失效引用时，排序预览不会继续。
系统不会按相同 wave 编号自动替换。

## 保存与项目切换

保存使用版本和幂等请求键。
版本冲突返回 409，并保留本地修改。
响应丢失时，使用原请求重试。
保存结果未确认时，界面暂停编辑。
登录失效时，画布保留本地草稿。
重新登录入口在新标签页打开。
恢复写入前，画布核对登录账号与原账号一致。
账号不一致时，画布拒绝继续写入。

项目切换支持保存、舍弃或取消。
项目草稿下拉选中后直接发起切换。
切换先结束字段编辑，再检查未保存修改。
取消切换后，下拉框仍显示当前项目。
浏览器历史切换同样检查未保存内容。
清空画布不删除保存记录，并支持撤销。
项目草稿下拉框选定项目后，可点击“删除项目”。
确认框显示待删除项目的名称。
删除项目会删除保存草稿、验证结果及排期。
警告：项目删除无法撤销。
删除当前项目会舍弃未保存修改并打开空白项目。
删除结果未确认时，使用原请求重试。

赛程筛选支持项目、stage、graph 和 wave。
session、日期和比赛名称也可以筛选。
无有效验证的项目会明确排除。

## 模型和接口

普通编辑在浏览器中完成，不请求编辑或分析接口。
新增、连线、属性、Stage、子图和撤销立即更新本地草稿。
目录加载后，服务端编辑接口不可达也不影响这些操作。
刷新页面前仍需保存草稿。

“分析草稿”按需请求完整来源和业务诊断。
分析期间可以继续编辑，过期响应不会覆盖草稿。
编辑后，页面提示尚未分析或分析结果已过期。
未分析时，节点和端口仍可使用，未知容量显示待定。

“保存草稿”只持久化草稿快照。
“验证保存版本”生成服务端 WavePlan。
正式预览和 Session 排期仍使用该保存版本的验证产物。
草稿分析不能代替验证保存版本。

图格式标识为 canvas，不使用版本后缀。
顶层字段为 schemaVersion、nodes、edges、stages。
只接受当前配置，旧格式不再进入编辑器。
Match ID 和计划 key 不因分组改变。

| API（/api/v1 下） | 职责 |
|---|---|
| GET /planning-canvas/catalog | 编辑协议、规则版本、默认值及结构预设 |
| GET /planning-canvas/samples/:name | 返回 v2 样例，不保存 |
| POST /planning-canvas/analyze | 主动分析草稿，返回完整诊断，不保存 |
| POST /planning-canvas/edit | 保留原子编辑 API，当前前端不调用 |
| GET/POST /planning-canvases | 项目列表及新建 |
| GET/PUT/DELETE /planning-canvases/:id | 读取、保存及删除项目 |
| POST /:id/validate | 生成并保存完整 WavePlan |
| POST /:id/preview | 读取该版本的验证产物 |
| GET /:id/schedule | 读取排期、旧快照和失效状态 |
| PUT /:id/schedule | 保存独立版本的 session 排期 |

全部接口检查当前会话和项目 owner。
图保存和排期保存都需要请求键。
排期写入还检查当前 WavePlan 摘要。
独立表不写入正式赛事运行数据。

目录的 editorProtocol 为 canvas-editor。
ruleCatalogVersion 标记规则目录版本。
samples 只包含结构模板，不含来源分析或 WavePlan。
协议不匹配时，页面提示刷新目录。
普通编辑使用 shared/planning-canvas 的共享规则。
后端保存仍独立复核结构、参数和连线。

预览计划键使用 canvas-plan 前缀。
保存冲突版本和赛制规则版本继续保留。
数据库启动时自动转换此前保存的 canvas-v2 名称及摘要。
转换保留节点、Stage、Session 和保存版本。
旧验证和排期已过期时，转换后仍显示过期。
已确认请求仍可用原键重试相同快照。
更新持久化实例前，先备份数据库。
回退应用时，需恢复对应的数据库备份。
