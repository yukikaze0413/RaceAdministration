# 赛程规划画布

入口为 /canvas-lab，访问需要登录。
独立赛程页面为 /canvas-lab/preview。
画布保存规划草稿，不记录真实比分。

本地入口：[打开画布](http://127.0.0.1:5010/canvas-lab)。
校园网入口：[打开画布](http://10.82.238.254:5010/canvas-lab)。
校园网访问取决于 WLAN 地址及防火墙规则。

## Stage、Wave、Session 与 Round

| 概念 | 用途 |
|---|---|
| stage | 画布框选的大分组，严格按阶段顺序执行 |
| wave | 验证自动生成的基本赛程单位 |
| session | 赛程页面的小分组，安排 wave 顺序和时段 |
| round | 瑞士轮中的轮次，整体归入一个 wave |

同一 wave 不能跨直接 graph 或 stage。
wave 内不能存在人员冲突和结果先后需求。
编号在每个 graph 内统一生成。
不同子图可以各自显示 wave 1。
引用使用身份标识，不使用显示编号。

stage 1 全部结束后，stage 2 才能开始。
stage 不改变子图层级和连线边界。
每个 wave 显示全部前置需求。
跨图共享人员也会产生执行顺序。

Swiss round 暂时表示整轮配对占位。
系统没有生成真实对阵或成绩。
单败和双败不使用 round 字段。

## 建图和分组

1. 从左侧组件库添加来源和比赛。
2. 点击输出端口，再点击目标输入端口。
3. 点击“框选模式”。
4. 在空白处拖出矩形，选择当前图的卡片。
5. 点击左侧 Subgraph 下方的“Stage · 分组所选”。
6. 检查阶段成员转移清单。
7. 确认转移，或取消保留原图。
8. 保存草稿。
9. 点击“验证保存版本”。
10. 查看右侧的验证批次和前置需求。

来源集合需要展开后才能连接 Match A/B。
Pool 输入按端口顺序拼接。
选择器和排序器不单独消耗 wave。
未加入阶段的真实比赛会收到诊断。

Ctrl/⌘ 点击可以增减多选。
Ctrl/⌘+G 可以封装同层卡片。
Ctrl/⌘+Shift+G 可以创建阶段。
封装与 stage 分组分别操作。
框选 subgraph 时，stage 纳入内部赛程。

点击阶段标题或左侧阶段列表，选中 Stage。
右侧属性显示名称、顺序和成员列表。
修改名称和顺序后点击“应用阶段属性”。
成员列表支持添加和移除比赛、瑞士轮。
选中 Stage 后，Delete 仅删除阶段。
删除 stage 保留比赛，并提示重新分组。
所有图编辑支持撤销和重做。
封装或展开后，验证重新计算 graph 归属。

## 参数与接口

普通点击卡片打开参数面板。
修改后点击“应用属性”。
输入端口在左侧，输出端口在右侧。
拖动标题移动卡片，拖动背景平移。
滚轮缩放，“适应全图”定位全部卡片。

参赛来源输出初始席位集合和初始种子。
逐席位端口保留已有连接。
Match 单方缺席时按轮空晋级处理。
Match 双方缺席时输出空席位。
轮空不占人员执行批次。
配置错误不会当作正常轮空。

悬空接口可以隐藏，但不会删除。
已经连接的接口保持可见。
子图收集内部全部开放输入和输出。
删除接口或缩容时，先检查连接影响。

新图不提供手填 batch 或 wave 编号。
wave 由验证统一生成。
新增比赛后，需要加入阶段并重新验证。

## 旧草稿迁移

1. 打开旧项目。
2. 点击“迁移新机制”。
3. 检查原 batch 和默认阶段。
4. 点击“应用迁移”，或点击“取消迁移”。
5. 保存草稿。
6. 验证保存版本。

迁移默认把原赛程归入阶段 1。
应用迁移只改变本地草稿。
保存后才写入 canvas-v2。
取消迁移保留原图和保存版本。
旧 batch 不再决定新图的 wave 分组。

## Session 排期

1. 打开顶部“打开赛程预览”。
2. 选择一个赛事项目。
3. 点击“新建 session”。
4. 选择待安排的 wave。
5. 调整 wave 顺序。
6. 填写开始和结束时间段。
7. 检查前置需求和时间诊断。
8. 点击“保存排期”。

时间使用含 UTC 偏移的 ISO 格式。
例如：2026-10-14T09:00:00+08:00。
结束时间必须晚于开始时间。
缺少时间可以保存草稿，但仍提示待确认。

同一 session 内，前置 wave 必须排在前面。
有跨 session 依赖时，时段不能重叠。
“预览依赖排序”先展示排序结果。
点击“应用依赖排序”后才改变本地列表。

wave 可以移除或移动到另一个 session。
同一 wave 不能重复安排。
未安排的 wave 显示在待排期列表。
排期按项目保存，并使用独立版本。

列表中的时间范围表示整个 session。
系统不把该范围当作每场比赛的开始时间。
缺少逐场时长时，时段容量仍待确认。

## 验证变化和失效修复

修改并保存图后，原验证产物失效。
重新验证可能改变 wave 成员和前置需求。
原 session 和绑定快照仍保留。

1. 在赛程页面读取排期版本。
2. 检查旧成员和旧前置需求。
3. 替换失效 wave，或移除旧引用。
4. 补充当前待安排的 wave。
5. 检查顺序和时间段。
6. 保存排期并绑定当前产物。

引用修复保留 session 名称和时间段。
存在失效引用时，排序预览不会继续。
系统不会按相同 wave 编号自动替换。

## 保存与项目切换

保存使用版本和幂等请求键。
版本冲突返回 409，并保留本地修改。
响应丢失时，使用原请求重试。
保存结果未确认时，界面暂停编辑。

项目切换支持保存、舍弃或取消。
浏览器历史切换同样检查未保存内容。
清空画布不删除保存记录，并支持撤销。
项目草稿下拉框选定项目后，可点击“删除项目”。
确认框显示待删除项目的名称。
删除项目会删除保存草稿、验证结果及排期。
警告：项目删除无法撤销。
删除当前项目会舍弃未保存修改并打开空白项目。
删除其他项目会保留当前草稿。
删除结果未确认时，使用原请求重试。

赛程筛选支持项目、stage、graph 和 wave。
session、日期和比赛名称也可以筛选。
无有效验证的项目会明确排除。

## 模型和接口

新图使用 canvas-v2。
顶层字段为 schemaVersion、nodes、edges、stages。
旧 canvas-v1 继续读取。
Match ID 和计划 key 不因分组改变。

| API（/api/v1 下） | 职责 |
|---|---|
| GET /planning-canvas/catalog | 组件默认值及规则目录 |
| GET /planning-canvas/samples/:name | 返回 v2 样例，不保存 |
| POST /planning-canvas/migrate | 返回迁移候选和原批次摘要 |
| POST /planning-canvas/analyze | 返回编辑诊断 |
| POST /planning-canvas/edit | 返回原子候选或影响确认 |
| GET/POST /planning-canvases | 项目列表及新建 |
| GET/PUT/DELETE /planning-canvases/:id | 读取、保存及删除项目 |
| POST /:id/validate | 生成并保存完整 WavePlan |
| POST /:id/preview | 读取该版本的验证产物 |
| GET /:id/schedule | 读取排期、旧快照和失效状态 |
| PUT /:id/schedule | 保存独立版本的 session 排期 |

全部接口检查当前会话和项目 owner。
图保存和排期保存都需要请求键。
排期写入还检查当前 WavePlan 摘要。
独立表不写入正式赛事运行数据。

## 本地启动与验证

项目根运行 node scripts/canvas-lab-preview.js。
先在 frontend 运行 npm run build。
隔离数据库为 output/local-preview/canvas-lab.sqlite。
CANVAS_LAB_HOST 可以指定 WLAN 监听地址。

测试使用临时 SQLite。
后端验收命令为 npm test。
前端验收命令为 npm test 和 npm run build。
浏览器验收覆盖 canvas-lab 和 canvas-mechanism 用例。
实施证据位于新机制 OpenSpec 变更目录。
