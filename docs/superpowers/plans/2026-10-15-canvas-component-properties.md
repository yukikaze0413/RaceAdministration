# 画布组件属性分类与面板调整计划

**目标：** 所有组件共享名称和坐标基础模型。属性面板区分可编辑属性、显示属性和内部属性。瑞士轮常用配置和应用按钮可直接操作。

**结构：** 保留 JSON 数据结构，以 TypeScript 基础接口和组件接口建立继承。属性面板共用名称和操作区。业务属性按组件显示，规则参数编辑器独立成文件。

**技术：** React、TypeScript、Vitest、Playwright。

**依据：** 本次用户要求及 `docs/PLANNING-CANVAS.md`。

## 属性分类

| 类别 | 字段 | 操作 |
|---|---|---|
| 通用可编辑 | name | 所有组件共用名称输入 |
| 业务可编辑 | params 中的业务参数 | 各组件分别显示 |
| 显示可编辑 | display | 共用显示设置，直接应用 |
| 内部保留 | id、kind、position、parentId | 不显示输入框，坐标通过拖动修改 |
| 派生只读 | ports、capacity、hiddenConnectedLoser | 属性面板不编辑 |
| 内部规则 | algorithm、release、templateOrigin | 保留数据，不提供输入框 |

### 各组件的业务属性

| 组件 | 可编辑字段 | 面板分组 |
|---|---|---|
| 参赛来源 | seats、mapping | 参赛席位、外部种子映射 |
| Match | bestOf、winnerRule、expectedTime、durationMinutes | 比赛参数、折叠的预计时间 |
| 瑞士轮 | ruleVersion、parameters、ranking | 赛制参数、高级规则、排名输出 |
| Pool | inputs | 输入顺序 |
| 展开器 | count | 数量可留空，由集合推导 |
| 选择器 | count、mode、seed | 数量、模式；随机模式显示种子 |
| 种子生成器 | count、mode、seed | 数量、模式；随机模式显示种子 |
| 子图 | custom、boundaries | 转为自定义、高级边界设置 |

canvas-v1 的 Match 另有 batch 字段。
单败、双败预设复用子图属性面板。
全部组件使用 `CanvasNode`。
`CanvasNode<Kind, Parameters>` 继承 `CanvasNodeBase`。
基础接口定义名称、坐标、身份、归属和显示属性。
组件接口增加类型、业务参数和派生结果。

## 约束

- 保留已有未提交修改。
- 保留 canvas-v1 与 canvas-v2、撤销、连线影响确认和保存流程。
- 不改变瑞士轮动态配对占位的业务含义。
- 属性应用不改写坐标、身份或图层归属。
- 不引入依赖，不自动提交。

## 核验重点

- 修改名称后，坐标和内部属性保留。
- 折叠字段保留旧值，规则切换清除旧规则参数。
- 逐轮覆盖仅列出已配置项，支持添加、修改和移除。
- 缺省规则值与嵌套覆盖合并时保留同级字段。
- 固定规则字段不可改成规则不允许的值。
