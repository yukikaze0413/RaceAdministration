# 画布连线与分组操作计划

前置提交：`52d2c03`。

## 已确定的行为

- 图中只保留 1 个选中端口，显示描边。
- 点击空白和拖动背景保留选择；非法目标替换选择且不改连线。
- 有效目标连接后清除选择；再次点击已选端口断开其连线并清除选择。
- 子图边界断开保留内部连线。
- 网络和权限失败继续显示错误。
- 创建连线仅使用画布端口，删除连线使用图中的选择和删除按钮。
- Stage 支持全部组件，Stage 与组件可用 Ctrl/⌘ 混合多选。
- 仅保留 Stage 分组入口。新增组件后选中新组件，清除旧组件和 Stage 选择。
- 编号工具维护已用编号和最新编号；新分组优先使用最小的可用编号，保存重载后仍可复用。
- 创建 Stage 操作先检查所选组件的阶段归属。
- 存在归属时加入顺序最低的 Stage；没有归属时才新建。
- 仅选中同一 Stage 的真子集时拆成新 Stage；选中 Stage 本身或选满成员时复用。
- 目标 Stage 的名称、顺序和原有成员保留。
- 所选成员归并到目标 Stage，不要求转移确认。
- 分组结束后删除所有 0 成员的 Stage，并释放占用编号。最新编号不回退。
- 子图在成员列表和选择列表中代表内部组件；赛程仍使用内部比赛。
- 移出子图中的单个组件时，旧 Stage 保留其余组件。
- 封装和展开保持阶段归属、节点身份及连线。
