## 当前功能

- Pool 已移除“输入顺序”属性编辑区，既有端口顺序保留。
- 展开器数量只读且不持久化，来源数量、输出数量和状态使用统一只读配置。
- 取前 K 名和随机 K 名是两个组件，支持补集及补集种子映射。
- 每个画布只保存最新 graph，version 是并发保存校验号，不是历史存档。

- canvas 使用 stage、wave 和 session。
- stage 采用全画布严格顺序。
- 验证自动分配 wave，并保存完整 WavePlan。
- session 在赛程预览中编辑和独立保存。
- 瑞士轮及循环赛每轮整体归入一个 wave。
- 瑞士轮实际配对仍是动态占位。

画布只接受 canvas，旧格式编辑与迁移入口已移除。
