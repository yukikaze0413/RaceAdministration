## 3. 精简模型提案

推荐独立领域模型与独立测试入口，复用现有规则目录、可复用纯函数和 React/SVG 视图能力。扩展旧 stage/group 模型会把自由端口绑回正式赛事；新建只供演示的前端模型则无法满足保存版本和领域复用要求。

规划图建议保存：`schemaVersion`、稳定 `canvasId`、节点与端口 ID、连接、子图边界、规则版本、参数及规划来源。布局另分区记录位置、展示尺寸、折叠、端口显隐；视图导航不改变比赛身份。保存响应包含 `version` 和语义摘要，验证/预览明确返回所依据的版本和摘要。

核心值采用明确的绑定域：

| 数据 | 内容 | 身份/顺序约束 |
|---|---|---|
| 单席位 | 稳定参赛来源引用或未来来源表达式 | 不是姓名，不以节点 ID 充当选手身份 |
| 有序席位集合 | 无重复引用的有序序列 | 当前索引表达种子顺序，不代表 Match A/B 位置 |
| 种子映射 | 席位引用 → 排序数值 | 枚举顺序无意义，不携带新增名额 |
| 位置排序模板（待确认） | 位置 → 排序数值，加 N 与算法版本 | 独立于席位引用；只能由 Pool 按拼接位置绑定 |

计算结果可区分：类型已知、容量已知、排列/身份待解析、存在规则缺口、已解析。组件输出是一次计算结果的不同投影；不保存两份可独立修改的集合顺序与种子映射。原竞技排名另作来源追溯。

未来 Swiss 排名、Match W/L 是表达式，预览不需要真实成绩。规则具备最终全排序语义时可以预览占位；排名规则缺失则明确未就绪，不以输入顺序冒充竞技最终名次。外部运行数据的解析入口后置，本次仅以独立测试夹具核验解析契约，不向结构写比分。

计划 key 建议使用独立 `canvas-plan-v1` 命名空间，以 canvasId 与稳定 Match 身份派生；封装、展开、改名及拖动不改变 key。子图转发不产生额外名额消费。

## 4. 必须先定案的接口语义

下表 C1～C7 已由用户“采用推荐方案”确认，作为本 change 的接口决定。

| 决策 | 推荐方案 | 可观察影响 |
|---|---|---|
| C1 集合的统一接口 | 每个集合出口配套当前顺序的 1～N 映射，可隐藏且无需连线 | Pool/Swiss/Selector/子图集合出口保持同一接口；排列待解析时映射也待解析 |
| C2 映射身份与并列 | key 为稳定席位引用；外部映射允许缺项/并列，Pool 稳定排序 | 不把排序数值等同竞技名次，竞技晋级并列需规则 |
| C3 无输入生成器 | 显式数量 N，输出位置排序模板，保存随机数种子和算法版本 | 不读取上游席位、不创建隐藏反向依赖；长度不适配时给出容量诊断 |
| C4 随机与超限 | randomN 固定 seed 后可复现；重新随机仅显式操作；N 超人数报错 | 验证和预览不自动换 seed，不静默缩减名额 |
| C5 展开器稳定性 | 端口 ID 按序位置稳定；重排改变位置所承载席位 | 缩容影响已连接端口时先展示影响，保留旧图，显式处理后原子应用 |
| C6 子图边界及预设 | 边界 ID 稳定；预设实例可显式转自定义，保留模板来源和内部 Match 身份 | 编辑/删除边界先展示外部连接影响；不自动把所有 W/L 当晋级出口 |
| C7 Swiss 最终输出 | 全段完成并确认后解析，含全体席位；规划时显示未来排名来源 | 无全排序规则、晋级切线并列未处理时阻止相应验证就绪，允许合法草稿保存 |

Match 无唯一胜败者时不生成虚假 W/L；本次不增加实际裁定策略。依赖 W/L 且未定义处理规则的图保留明确诊断。

## 5. 连接与验证提案

所有目标输入最多一个来源。单席位输出最多一条席位流；集合/种子输出允许多读。Pool 的席位/集合输入是显式联合类型，其他纯集合入口不隐式接受单席位。集合到 Match A/B 必须先展开。

新连线先在候选图移除源/目标旧冲突，再复验类型、引用、容量和环，成功才一次替换；失败保持旧图及撤销历史。重复连接无新边。连接/删除/配置/封装均支持撤销重做。Pool 输入按稳定端口序号汇集，始终保留一个空入口。

验证分为 schema/type、图结构、规划就绪、待解析身份条件。保存只要求 schema/type 合法，缺输入/规则等业务问题可以保存并定位。建立新连接必须满足局部合法性。预览只读取已保存且仍与验证摘要匹配的版本；保存新版本使旧验证/预览失效。409 和网络失败保留本地草稿，不自动采用远端。

多分支读取合法；下游同批次重复参与须按来源身份与比赛依赖验证，不能仅数边。Match W 与 L 是互斥未来来源，跨轮正常再次参赛不是重复。身份无法完全解析时记录条件，并在测试解析入口复验。
