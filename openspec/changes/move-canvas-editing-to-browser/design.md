## Goals / Non-Goals

**Goals:**

- 参考 ComfyUI 的环节分工，让普通编辑脱离网络等待。
- 保持现有图结构、规则版本和身份稳定性。
- 让节点和端口无需完整业务分析即可显示。
- 保留服务端保存、权限检查和权威验证。
- 用请求数量、编辑延迟和行为等价性共同验收。

**Non-Goals:**

- 本计划不替换 React、现有节点界面或画布渲染库。
- 本计划不增加自动保存、跨设备同步或多人协作。
- 本计划不移动 WavePlan 生成及正式赛程校验至浏览器。
- 本计划不增加真实瑞士配对、比分或赛事执行能力。
- 本计划不把 ComfyUI 的模型队列和 WebSocket 直接搬入赛事系统。

## Decisions

### D1. 普通编辑完全由浏览器完成

选择本地编辑和显式保存的方案。只缩减响应仍会保留网络往返；只做乐观新增则会继续面对逐次服务端回滚。两种方案都不能完成本次环节迁移。

| 操作 | 目标位置 | 网络时机 |
|---|---|---|
| 目录、样例、预设模板 | 后端提供，前端按版本缓存 | 初始化或显式刷新 |
| 新增、删除、属性、显示、连线和断开 | 浏览器 | 无编辑请求 |
| Stage、封装、展开、边界及转自定义 | 浏览器 | 无编辑请求 |
| 选择、拖动、缩放、撤销和重做 | 浏览器 | 无编辑请求 |
| 草稿完整分析 | 后端 | 用户主动选择“分析草稿” |
| 保存图、删除项目和读取项目 | 后端 | 用户明确操作 |
| 验证保存版本、读取预览和排期 | 后端 | 用户明确操作 |
| Session 增删、排序和时间输入 | 浏览器草稿 | 保存排期时请求 |

初始化后，即使分析、编辑和迁移接口不可达，普通编辑也能完成。
页面重新加载仍需要服务端资源和账号会话。
本计划不承诺完整离线启动或浏览器关闭后的草稿恢复。

### D2. 抽取共享编辑核心，保留服务端完整复核

新增 shared/planning-canvas 共享包，源码使用 TypeScript。
构建同时产出浏览器 ESM、Node.js CommonJS 和类型声明。
前端与后端通过本地包引用同一份源码，避免分别维护图规则。
构建使用现有 TypeScript 工具链，不引入第三方运行依赖。
更新启动、构建和测试脚本，先构建共享包。
构建产物不纳入 Git，干净检出能按文档生成产物。

| 模块 | 职责 |
|---|---|
| shared/planning-canvas/model | 图类型、结构解析、端点、端口、容量和稳定身份规则 |
| shared/planning-canvas/edit | 原子候选、影响清单、确认、Stage 和子图 |
| shared/planning-canvas/editor-model | 节点、端口、边界、连接索引和结构诊断 |
| shared/planning-canvas/rules | 浏览器和后端共用的参数规则及旧格式拒绝检查 |
| backend/src/planning-canvas/graph.js | 兼容入口、权威领域检查、服务端摘要和分析组合 |
| frontend/.../editor-state.ts | 当前草稿、编辑版本、撤销记录、命令和未保存状态 |
| frontend/.../analysis-state.ts | 草稿分析、验证结果、过期状态及请求归属 |

接口草案为 applyEdit(graph, action, context)、deriveEditorModel(graph, catalog)。
applyEdit 返回 applied、unchanged、requiresConfirmation 或 invalid。
返回结果包含候选图或诊断，不隐式写库或请求网络。
ID 由 context.createId 注入；浏览器沿用兼容非安全 HTTP 的 requestKey。
测试注入固定 ID，比较候选、影响和撤销结果。

不能直接把整个 graph.js 放进浏览器。
该文件依赖 Node.js crypto、领域注册表和预设编译器。
拆分时把字段与参数规则移入共享纯函数。
Swiss 注册目录的纯数据和参数规则与编译、运行能力分开。
后端在共享结构检查之后继续检查支持的领域规则版本。
浏览器不能用目录检查代替服务端校验。

### D3. 预设在目录加载时准备，新增时只克隆模板

组件目录增加编辑协议版本、规则目录版本和结构预设模板。
模板包含节点、内部边、边界和规则版本，不包含分析结果。
后端用既有 single-cut-v2、gsl-classic-v1、de-standard-v1 编译器生成模板。
前端新增预设时克隆模板，并统一重映射节点、边和边界引用。
随后按现有规则处理 parentId、Stage 和选择状态。
浏览器不另写一套赛制编译器。

模板和目录版本不匹配时，保留已有草稿和受支持的本地编辑。
依赖缺失模板的新增入口显示刷新目录操作。
客户端不能静默换用别的赛制版本。

### D4. 把编辑模型与完整分析分开

CanvasView 从 editorModel 获取节点和端口，不再读取 analysis.nodes。
editorModel 同时生成连接索引和可见子图边界。
容量沿现有结构规则推导，不能确定时保留未知状态。
未知容量不能伪造可连接的席位端口。

端口类型、输入占用、跨图边界、循环和参数合法性在本地检查。
删除、缩容和边界变更先生成影响清单。
确认令牌绑定本地 graphEpoch 和 revision。
确认前图已变化时，重新生成影响清单，旧令牌不能提交。
客户端令牌与服务端 expectedDigest 分开，不伪造服务端摘要。
旧编辑 API 继续使用原摘要协议。

画布只接受当前 canvas 格式，不恢复旧格式连接检查、迁移入口或兼容 Worker。

### D5. 完整分析按需执行，结果不能改写草稿

新增“分析草稿”操作，调用现有 /planning-canvas/analyze。
默认编辑不自动分析，不用 debounce 掩盖逐次整图请求。
服务端完整分析仍可计算来源、集合、冲突和临时波次。
该结果只供检查，不能成为正式预览或 Session 排期依据。
WavePlan 的权威产物继续由验证保存版本生成。

| 状态 | 页面行为 |
|---|---|
| 未分析 | 显示本地结构诊断，集合和来源结果提示尚未分析 |
| 分析中 | 保持编辑，显示当前分析版本 |
| 当前结果 | 展示与草稿版本匹配的来源、集合和业务诊断 |
| 结果过期 | 保留可识别的旧结果或折叠旧结果，明确标记过期 |
| 分析失败 | 保留当前草稿，允许重试，不显示为空结果 |

保存后的服务端验证与草稿分析使用独立状态。
只改布局也使已有验证失效，沿用当前整图摘要规则。
修改图后，旧 Session 和绑定快照继续保留并标记失效。
本计划不按显示编号重新绑定 Wave。

### D6. 用本地命令顺序和请求归属管理并发

每次载入、重置或切换项目生成新的 graphEpoch。
每次已提交的本地内容编辑增加 revision。
graphEpoch、revision、项目 ID 和请求 ID 共同标记异步操作。
撤销后也增加 revision，避免旧结果因编号复用而被接纳。
本地命令串行读当前草稿，不等属性 HTTP 队列。

数值输入的暂时空值、中文输入法组合文本保留在表单缓冲。
合法属性按当前自动生效规则提交；席位及映射在 blur 提交。
保存和项目切换先完成当前文本编辑，再读取快照。
非法缓冲阻止保存并定位字段，不静默丢失输入。
文本会话和一次拖动各形成一组撤销，避免逐字制造撤销记录。

草稿分析结果只能更新分析状态，不能安装 graph。
切换、清空、撤销和后发请求使不匹配的响应失效。
取消请求与归属检查同时使用，取消失败也不能接纳旧响应。

保存以明确快照执行，保留现有待确认保存期间暂停内容编辑的规则。
保存响应不触发 /edit 或完整分析。
409 保留草稿和字段缓冲，显式处理后再保存。
响应丢失继续用同一请求键和同一快照重试。
保存失败时不能继续验证或切换到目标项目。
验证或预览响应返回时若草稿已变，仅保留为旧保存版本结果。

### D7. 保留服务端信任边界和兼容 API

保存重新执行结构、参数及边检查，不信任客户端的“检查通过”。
保存允许业务不完整但结构合法的草稿。
验证重新计算来源、冲突和 WavePlan，不接纳客户端验证缓存。
权限、会话、expectedVersion、幂等请求键和产物摘要继续由服务端检查。
非法字段、伪造运行数据及越权读取继续拒绝。

保留 /edit、样例及既有保存、验证、预览接口。迁移接口保持移除。
新前端不再调用 /edit 和 /migrate。
旧 API 通过共享核心保持兼容，不能因迁移直接删掉。
已有画布命名转换按 D9 执行。
项目删除仍需明确确认，不能混同本地删除节点。

### D8. 控制前端计算和绘制成本

用本地修订和保存快照跟踪修改，不在每次渲染序列化整图。
撤销回到保存内容时恢复干净状态。
内容比较只发生在命令提交等确定边界，不能只靠修订号判断相等。
建立节点、边和端口索引，避免逐端口扫描整图。
拖动视觉更新每帧合并，拖动完成提交一次编辑历史。
按节点及端口尺寸变化维护测量缓存。
平移和缩放复用世界坐标，不能重新测量全部端口。
分析结果到达不能重新初始化所有属性输入。

先保留现有渲染方案。只有指标未达标且记录显示渲染仍占主要耗时，才另行提出替换渲染库的计划。

### D9. 画布标识不使用版本后缀

图的 schemaVersion 值统一为 canvas，编辑协议为 canvas-editor，预览计划键前缀为 canvas-plan。
保存冲突版本、赛制规则版本和规划器版本保留。
旧画布名称不再作为可编辑格式进入共享解析器。

数据库启动时执行一次原子命名转换，记录在 schema_migrations 第 5 项。
转换同时更新草稿、验证、绑定排期和幂等结果中的对应摘要。
节点、连线、Stage、Session 身份及并发版本保持。
过期验证和排期继续保持过期，不能借改名恢复有效状态。
转换失败时回滚，重复启动不重复转换。

原幂等指纹保留；canvas_name_digests 记录名称转换前后的摘要对应。
已有请求重试只匹配原内容或改名后的相同快照，不允许改内容后复用旧键。
外部新请求只接受 canvas；旧名称只用于数据库转换和已确认请求的指纹核对。
更新隔离预览前创建数据库备份，不改正式业务数据库。

## Migration Plan

| 阶段 | 实施结果 | 出口 |
|---|---|---|
| U0 基线 | 固定现有动作、格式、接口和性能样例 | 有独立预期及请求统计 |
| U1 共享核心 | 拆出纯编辑规则，后端兼容入口复用 | Node.js、浏览器构建及行为对照通过 |
| U2 本地状态和编辑模型 | 节点及端口脱离 analysis，接入本地命令 | 核心本地编辑不请求后端 |
| U3 全量编辑迁移 | 属性、Stage、子图、预设和确认完成 | 本地完整编辑序列与旧行为等价 |
| U4 分析及持久化 | 按需分析、保存、验证和排期接回 | 旧响应、冲突及失效恢复通过 |
| U5 绘制和网络验收 | 控制重绘、测量缓存并验收性能 | 功能、网络和延迟指标共同通过 |

先在隔离预览环境完成整套迁移，再更新常用预览。
实施期间保留旧服务端编辑 API，允许回退到前一套前端构建。
回退前先保存或保留未保存草稿的快照，不能覆盖当前本地编辑。
画布统一为 canvas；回退必须恢复匹配的应用构建与数据库备份。
提交与推送按用户明确要求执行，不写入 Notion。

## Acceptance

以下是拟定的实施验收目标，不是已通过结果。

1. 初始化稳定后，新建、属性、连线、Stage、子图及撤销重做的编辑请求数为 0。
2. 阻断 /edit、/analyze、/migrate 后，全部普通编辑仍可完成。
3. 在 100 毫秒延迟、1 Mbps 上传和下载带宽下，本地新增延迟不依赖服务端响应。
4. 参考桌面浏览器中，36 节点样例新增至绘制代理的第 95 百分位耗时不超过 100 毫秒。
5. 同环境中，144 节点样例对应耗时不超过 150 毫秒。
6. 每组预热后至少测 30 次，分别记录本机和模拟网络结果。
7. 360、768、1440 像素宽度完成编辑、保存、验证和排期回归。
8. 记录实际手机、校园网地址、图规模和新增耗时；模拟器结果不能替代手机验收。
9. 对照共享结果与手写预期，覆盖非法输入、重复操作、影响确认、旧格式拒绝、Stage 和子图。
10. 保存 409、响应丢失、身份失效、项目切换和分析乱序都保留正确草稿。
11. 既有 WavePlan、Swiss 占位、轮空、Session 失效和权限用例继续通过。

性能脚本记录点击处理、请求、响应接收、DOM 提交和绘制代理各阶段。
初始化请求与预设目录加载计入启动指标，不得算作编辑请求。
使用真实业务副本和合成样例分别报告，不能把合成图称为真实业务验收。

## Risks / Trade-offs

- 图规则分叉 → 从同一源码构建共享核心，并增加独立预期测试。
- 前端计算变重 → 区分结构模型和完整分析，普通编辑不执行完整来源分析。
- 本地确认后图变化 → 绑定草稿代次和修订，变化后重新确认。
- 连续输入被旧响应覆盖 → 取消图安装式分析，只接纳匹配版本的结果。
- 前端绕过规则 → 服务端保存和验证各自重新检查。
- 新旧包或目录不匹配 → 版本握手，保留草稿和显式刷新入口。
- 暂停编辑时没有最新业务诊断 → 明确显示未分析或过期，并提供主动分析。
- 手机性能差异 → 真机验收单独记录，不用桌面阈值冒充真机结论。
