# Spec Delta

## MODIFIED Requirements

### Requirement: PR3 分流与结果就绪
系统 SHALL 支持从不同来源分流至不同后续阶段，包括跳过中间阶段；所有依赖形成有向无环图。预演只消耗标记已结束的来源快照，未结束来源、名额不足或未知同分策略返回就绪阻塞。结果快照的版本与本次结构版本 MUST 随预演报告返回；实际执行仍额外校验运行规则与真实名单。

本次增加真实路由执行：已完成且排名确定来源快照，在整轮确认事务中按同一筛选与映射规则执行；所有必需来源未齐时不生成部分下游。

#### Scenario: 四组冠军分流
- **WHEN** A/B/C/D四组冠军分别a/b/c/d，预设A/B进入阶段B的seed1/2，C/D跳至阶段C的slot1/8
- **THEN** 预演输出a/b至B、c/d至C，与人工E6预期一致，不强制c/d进入B

#### Scenario: 来源未齐
- **WHEN** 任一必须来源未结束或只提供1人但路由固定名额2
- **THEN** 系统报告缺失来源或名额不足，不返回可应用的部分分配
