# Proposal

## Why

上一轮前端已交付并提交，但密码限制、手填带时区时间和只有卡牌/格斗分类的赛事创建流程增加了输入负担。用户在2026-10-05提出反馈，并要求参考对话01a10857-8f97-78e2-87df-deb2afe3be9c复用成熟通用能力；本变更形成可实施的后续规格与任务，当前处于实施。2026-10-06手机实测反馈新增现有预览服务版本与HTTP保存兼容、表单层级及账号修改密码修复；旧切片自动化证据不代表真实手机接受。

## What Changes

- 取消注册与登录的产品密码最短/最长字符数限制，保留非空字符串、原样派生摘要、请求体资源限制和限流；兼容已注册账号。
- 评估成熟认证API/库（Supabase Auth、Auth.js），记录现有身份和赛事所有权兼容性、账号迁移、密码策略冲突、服务依赖及决策。此轮不批准切换身份提供方，不启用第三方登录或邮件恢复。
- 用成熟中文日期时间组件替代手填ISO文本；显示所用时区，支持清空和编辑回显，服务端继续保存UTC时刻。优先评估引用对话的Ant Design DatePicker，不接入Google日历等外部排程服务。
- 增加游戏预设选择：街霸六与影之诗；先选card/fighting分类以筛选，再选最终游戏预设，旧分类赛事保持可读可编辑，不自动猜测游戏。
- 建立版本化资源目录：街霸六角色头像/立绘，影之诗卡片头像/插画与职业图标；记录来源、实体ID、语言、版本、图片用途和可用状态。已核实的官网页面与尚未核实的图片地址分开；图片失败不阻断赛事管理。
- 补充当前密码验证后的修改密码及主动退出入口；修改后撤销所有会话，保持账号与赛事所有权ID。用户已确认注销为永久删除账号及相关数据；增加头像、显示名、用户名编辑及只读唯一ID，删除前查看范围并验证当前密码。
- 修复实际HTTP局域网保存与预览后端版本不一致，验收必须在真实手机预览地址完成创建、刷新和编辑。
- 保持报名、角色/卡组报分、对阵和比赛运行不可用；资源预设不等于已实现这些领域。

已确认：四项用户反馈及参考对话。用户进一步确认原版与Worlds Beyond统一为“影之诗”，共用gameId=shadowverse、游戏入口和职业列表；死灵、吸血鬼、梦魇独立并列，不合并。素材保留来源版本和语言用于追踪，不要求用户选择版别，也不按版别限制通用预设。密码仅要求非空，不增加复杂度规则。未决：认证提供方、游戏素材分发方式及具体头像/立绘文件。

## Capabilities

### New Capabilities

- `game-presets`: 稳定游戏/资源ID、样例预设、来源版本、旧分类兼容和资源失败降级。
- `friendly-datetime-input`: 中文日期时间选择、明确时区、UTC往返、非法时间与键盘/移动端使用。

### Modified Capabilities

- `account-session`: AC1取消产品密码长度策略，保持身份与资料边界；认证方案研究只在design/tasks中，不新增未接入的登录承诺。
- `tournament-catalog`: TC1增加可选gameId与派生分类，TC2增加按游戏筛选，保持隐私、版本和幂等要求。

## Impact

前端AccountPage、MetadataForm、赛事列表/详情/筛选，后端accounts/sessions/catalog及相应HTTP/组件/浏览器测试；需要新增游戏资源目录API和前端组件依赖。既有SQLite记录与幂等响应须兼容，不改已冻结结构。资源研究见research.md；上一轮基线1db793a，两个已归档change的完成记录保留。原始提案的只规划阶段已结束；当前按切片实施与真实验收，素材仍待核实，不提供生产迁移或部署；后续实施与验收后才同步正式规格及归档。
2026-10-07用户修订：账户页风格与工作台统一，先看资料再按需编辑/确认；注销赛事范围按当前拥有权，新建默认归创建账号。沿用7.3–7.5修订验收，不以修正UI重复新增完成点数。
