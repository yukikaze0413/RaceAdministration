# Proposal

## Why

上一轮前端已交付并提交，但密码限制、手填带时区时间和只有卡牌/格斗分类的赛事创建流程增加了输入负担。用户在2026-10-05提出反馈，并要求参考对话01a10857-8f97-78e2-87df-deb2afe3be9c复用成熟通用能力；本变更形成可实施的后续规格与任务，当前只规划。

## What Changes

- 取消注册与登录的产品密码最短/最长字符数限制，保留非空字符串、原样派生摘要、请求体资源限制和限流；兼容已注册账号。
- 评估成熟认证API/库（Supabase Auth、Auth.js），记录现有身份和赛事所有权兼容性、账号迁移、密码策略冲突、服务依赖及决策。此轮不批准切换身份提供方，不启用第三方登录或邮件恢复。
- 用成熟中文日期时间组件替代手填ISO文本；显示所用时区，支持清空和编辑回显，服务端继续保存UTC时刻。优先评估引用对话的Ant Design DatePicker，不接入Google日历等外部排程服务。
- 增加游戏预设选择：街霸六与影之诗；用户选择游戏，card/fighting只作分类元数据，旧分类赛事保持可读可编辑，不自动猜测游戏。
- 建立版本化资源目录：街霸六角色头像/立绘，影之诗卡片头像/插画与职业图标；记录来源、实体ID、语言、版本、图片用途和可用状态。已核实的官网页面与尚未核实的图片地址分开；图片失败不阻断赛事管理。
- 保持报名、角色/卡组报分、对阵和比赛运行不可用；资源预设不等于已实现这些领域。

已确认：四项用户反馈及参考对话。规划假设：密码仅要求非空，不增加复杂度规则；影之诗先按原版、zh-tw源资料记录，版本问题已向用户提出，未答复前不是最终游戏版本决定。未决：认证提供方、游戏素材分发方式及可核实的具体头像/立绘文件。原版与Worlds Beyond不得混用。

## Capabilities

### New Capabilities

- `game-presets`: 稳定游戏/资源ID、样例预设、来源版本、旧分类兼容和资源失败降级。
- `friendly-datetime-input`: 中文日期时间选择、明确时区、UTC往返、非法时间与键盘/移动端使用。

### Modified Capabilities

- `account-session`: AC1取消产品密码长度策略，保持身份与资料边界；认证方案研究只在design/tasks中，不新增未接入的登录承诺。
- `tournament-catalog`: TC1增加可选gameId与派生分类，TC2增加按游戏筛选，保持隐私、版本和幂等要求。

## Impact

前端AccountPage、MetadataForm、赛事列表/详情/筛选，后端accounts/sessions/catalog及相应HTTP/组件/浏览器测试；需要新增游戏资源目录API和前端组件依赖。既有SQLite记录与幂等响应须兼容，不改已冻结结构。资源研究见research.md；上一轮基线1db793a，两个已归档change的完成记录保留。本次不改业务代码、不下载素材、不提供生产迁移或部署；后续实施与验收后才同步正式规格及归档。
