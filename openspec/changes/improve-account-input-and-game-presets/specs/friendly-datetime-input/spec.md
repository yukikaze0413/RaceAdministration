# Spec Delta

## Purpose

为赛事基础资料提供可直接操作的中文日期和时间输入，减少用户手写ISO8601字符串的负担，并确保界面选择与后端保存表示同一时刻。明确时区、可选留空、编辑回显与可定位错误，使不同设备和浏览器环境不会静默改变比赛开始时间。

## ADDED Requirements

### Requirement: DT1 日期时间选择与可选留空
系统 SHALL 提供中文日历与时间选择，允许键盘输入、键盘导航及清空；用户不需要手写ISO8601串。开始时间仍为可选，清空提交null，不自动赋值为当前时间或把午夜当成未知。编辑历史记录回显同一时刻，包括已有秒和毫秒；未操作时间字段的其他资料修改不得改变原时间。360/768/1440宽度下控件与弹层可使用，不造成页面水平溢出，错误与选择取消具有明确焦点归属。

#### Scenario: 选择与编辑
- **WHEN** 用户用日历选择2026-10-05 10:30、使用UTC+08:00后保存并重新编辑
- **THEN** 保存时刻为2026-10-05T02:30:00.000Z，回显为同一10:30；只修改赛事名称不改变该时刻

#### Scenario: 清空时间
- **WHEN** 用户清空已经填写的开始时间并保存
- **THEN** 服务端保存null，页面显示开始时间未定，不伪造一个日期

#### Scenario: 移动端与键盘
- **WHEN** 用户在360宽度或只用键盘选择日期、时间后取消或确认
- **THEN** 可以完成操作，弹层不遮断确认控件，焦点回到触发输入，原输入在取消时不丢失

### Requirement: DT2 明确时区与错误输入
系统 SHALL 在时间输入处明确展示和允许选择固定UTC偏移，默认UTC+08:00；固定偏移支持UTC-12:00至UTC+14:00的15分钟增量，本切片不把固定偏移宣称为带夏令时的地区时区。前端以所选偏移转换UTC，服务端验证带时区ISO日期并保存UTC；切换展示偏移不静默改变已选时刻，清空偏移或非法日期阻止保存并定位时间字段。浏览器自身时区变化不改变提交时刻，日期组件不代表自动排程、外部日历同步或报名截止规则已实现。

#### Scenario: 浏览器时区不同
- **WHEN** UTC环境和UTC+08环境用户均选择2026-10-05 10:30且输入偏移为UTC+08:00
- **THEN** 两者提交相同UTC时刻，浏览器本地环境不参与隐式转换

#### Scenario: 非法日期与冲突
- **WHEN** 用户输入不存在的日期、缺失偏移，或保存时遇到版本409
- **THEN** 非法输入有可定位错误且不写入；409保留已输入时间和其偏移，必须显式确认才能替换服务器版本
