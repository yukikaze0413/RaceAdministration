# Spec Delta

## MODIFIED Requirements

### Requirement: AC1 注册与个人资料
系统 SHALL 使用用户名、显示名和密码注册账号；用户名为3–32位ASCII字母、数字或下划线并按小写判重，显示名为1–40个Unicode码点的纯文本，密码必须为非空字符串，产品不设最短/最长字符数，不截断、不去空格、不增加字符组合规则。注册和登录使用一致策略；超过既有请求体资源上限的请求仍按413拒绝，这不是密码长度策略。创建成功不自动授予任何已有赛事权限。个人资料允许当前用户更改显示名、用户名和头像，唯一ID不可修改，不收集电话、证件或卡组等未确认字段。

#### Scenario: 注册与重启读取
- **WHEN** 用户注册合法账号并在服务重启后登录
- **THEN** 账号仍存在且显示名一致，密码和密码摘要不出现在响应中

#### Scenario: 重名或非法注册
- **WHEN** 用户提交已存在的大小写变体用户名或非法字段
- **THEN** 返回字段可定位错误，不建立第二账号，不回显密码

#### Scenario: 短密码与长密码
- **WHEN** 用户使用1个字符或超过128及1024个字符但请求体未超限的非空密码注册后登录
- **THEN** 注册与登录均不因长度拒绝，摘要使用完整原始密码，原有账号仍可正常登录

#### Scenario: 空值与资源上限
- **WHEN** 密码为空或非字符串，或整个请求体超过1MiB
- **THEN** 空值注册返回字段错误、非法登录保持统一凭据错误；超大请求返回413，不创建账号、不回显或记录密码

## ADDED Requirements

### Requirement: AC4 当前密码修改与退出登录
系统 SHALL 在已登录的个人资料页面提供退出登录和修改密码。修改密码必须验证当前密码，新密码为原样非空字符串且前端确认两次一致；不新增长度或复杂度限制。成功修改必须在同一事务更新原用户密码摘要与随机salt、保留用户ID及既有赛事所有权，并撤销该用户所有登录会话。当前会话已撤销、凭据并发变化、错误当前密码或非法新密码均不得部分写入；旧密码在途登录不得在修改后建立会话。修改密码受原有Origin/JSON和限流保护，不返回或记录密码/摘要。成功提示使用新密码重新登录；退出登录撤销当前会话并离开私有页面。永久注销另由AC6定义。

#### Scenario: 修改密码后重新登录
- **WHEN** 已登录用户输入正确当前密码、非空新密码并确认
- **THEN** 原ID及自有赛事不变，全部旧会话撤销，旧密码不能登录，原样新密码可登录并显示修改成功提示

#### Scenario: 密码错误和竞争
- **WHEN** 当前密码错误、确认密码不一致、请求来自其他Origin，或另一密码修改/在途旧密码登录与本次竞争
- **THEN** 非法请求有可定位错误、不改变账号；只一次有效修改成功，旧凭据不得创建新会话

#### Scenario: 主动退出
- **WHEN** 用户在个人资料点击退出登录并确认
- **THEN** 当前cookie及服务端会话失效，公共页显示登录入口，私有页要求重新登录

### Requirement: AC5 账户资料与固定身份
系统 SHALL 使用与其他工作台页面一致的panel、字体、按钮和间距；初始展示头像、显示名、登录用户名及只读唯一UUID总览，不直接铺开编辑表单。点击头像、修改名称、修改用户名、修改密码、退出登录或删除账号后，才显示对应输入或确认弹窗；取消不保存，关闭后焦点回到触发入口。当前用户可修改显示名、头像和用户名；用户名按原注册规则小写判重，改变时必须验证当前密码。更新不得改变 ID、赛事所有权或覆盖并发密码更新。旧账户无头像返回 null，默认头像不依赖外部服务。PNG/JPEG/WebP 经客户端压缩后服务端解码限制像素和体积、裁切为256平方像素WebP并移除元数据；SVG、动图、损坏文件和外部URL不得保存。

#### Scenario: 资料修改与重启
- **WHEN** 用户上传头像、修改用户名和显示名并刷新或重启
- **THEN** 新资料保留，旧用户名不再登录，ID 和赛事归属保持不变，密码摘要不返回

#### Scenario: 非法与竞争
- **WHEN** 用户名重复、密码验证失败、伪造 ID、非法头像或凭据并发改变
- **THEN** 返回错误且无部分写入，旧资料保留

#### Scenario: 资料总览与按需操作
- **WHEN** 用户进入账户页并点击头像、修改名称或账号操作
- **THEN** 初始只读资料完整，只有对应弹窗出现，取消不写入或保留草稿；保存后回总览显示已存资料

### Requirement: AC6 永久注销
系统 SHALL 将注销实现为数据库永久删除当前账号及其头像、凭据、全部会话、目录幂等记录、当前拥有的系列、赛事、配置和冻结快照；赛事删除仅按当前ownerId=user.id筛选，不按历史创建者；创建赛事默认ownerId取当前认证账号。已归他人所有的赛事及聚合保持原样，即使历史由本账号创建；目前归本账号所有的赛事才删除，不新增所有权转让接口。独立保留退出登录。界面展示删除范围数量，用户输入当前密码与当前用户名并确认不可恢复后提交预览令牌。服务器再次验证身份、凭据和数据范围，在一个事务中按外键顺序删除；范围变化返回409要求重看。历史跨账号关联返回409，不能误删他人数据或留下悬挂引用。请求受 Origin、JSON 与20次/15分钟限流保护。成功清除cookie、身份和私有页面，显示删除完成；仅用专用临时账户验证。

#### Scenario: 全量删除
- **WHEN** 已登录用户确认当前范围并提交正确密码和用户名
- **THEN** 账号及所有自身关联行消失，重启后仍不存在，他人数据不变，用户名可重新注册但获得新 UUID

#### Scenario: 删除失败
- **WHEN** 密码或确认错误、预览过期、存在跨账号引用或数据库故障
- **THEN** 不部分删除，事务回滚并提供错误，未成功不得显示完成

#### Scenario: 移动端确认
- **WHEN** 用户在360px宽度查看和取消注销
- **THEN** 弹窗内容无横向溢出，键盘焦点限制在弹窗，取消后回到入口且无写入

#### Scenario: 当前赛事所有权
- **WHEN** 用户创建赛事，或其历史创建赛事已归他人而其他赛事目前归其所有，并确认注销
- **THEN** 创建默认归当前账号；注销仅删除当前拥有赛事，已归他人赛事及配置保持不变，预览与删除范围一致
