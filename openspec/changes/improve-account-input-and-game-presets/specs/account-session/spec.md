# Spec Delta

## MODIFIED Requirements

### Requirement: AC1 注册与个人资料
系统 SHALL 使用用户名、显示名和密码注册账号；用户名为3–32位ASCII字母、数字或下划线并按小写判重，显示名为1–40个Unicode码点的纯文本，密码必须为非空字符串，产品不设最短/最长字符数，不截断、不去空格、不增加字符组合规则。注册和登录使用一致策略；超过既有请求体资源上限的请求仍按413拒绝，这不是密码长度策略。创建成功不自动授予任何已有赛事权限。个人资料只允许当前用户更改显示名，不收集电话、证件或卡组等未确认字段。

#### Scenario: 注册与重启读取
- **WHEN** 用户注册合法账号并在服务重启后登录
- **THEN** 账号仍存在且显示名一致，密码和密码摘要不出现在响应中

#### Scenario: 重名或非法注册
- **WHEN** 用户提交已存在的大小写变体用户名或非法字段
- **THEN** 返回字段可定位错误，不建立第二账号，不回显密码

#### Scenario: 短密码与长密码
- **WHEN** 用户使用1个字符或超过128及1024个字符但请求体未超限的非空密码注册后登录
- **THEN** 注册与登录均不因长度拒绝，摘要使用完整原始密码，原有账号仍可正常登录

#### Scenario: 空值与资源上限
- **WHEN** 密码为空或非字符串，或整个请求体超过1MiB
- **THEN** 空值注册返回字段错误、非法登录保持统一凭据错误；超大请求返回413，不创建账号、不回显或记录密码
