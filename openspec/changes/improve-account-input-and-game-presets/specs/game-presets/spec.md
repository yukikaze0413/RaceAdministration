# Spec Delta

## Purpose

通过具体游戏预设和可追踪的资源目录，帮助赛事创建者和浏览者识别比赛所属游戏，减少只有卡牌或格斗分类的信息缺失。游戏名称、角色、卡片和职业素材与赛事规则及赛果分离，资源失效也不影响已保存赛事的读取与管理。

## ADDED Requirements

### Requirement: GP1 稳定游戏预设与版本
系统 SHALL 提供版本化游戏目录，首批样例为street-fighter-6与shadowverse。影之诗原版与Worlds Beyond共用shadowverse游戏ID、入口和职业资源列表，不要求选择版别。每项包括稳定ID、显示名、分类、资源目录版本及状态，实体/素材保留来源版本作为出处。影之诗职业包括精灵、皇家、巫师、龙族、死灵、吸血鬼、梦魇、主教、复仇者，中立为非职业类别。死灵、吸血鬼、梦魇拥有不同稳定职业ID并列展示，MUST NOT 自动合并或相互替换。目录与实体ID不得依赖图片地址或数组位置，更新目录不自动迁移已存赛事或修改冻结配置。支持的实际赛制运行集合保持为空，沿用structure-v1/routing-v1；游戏预设不提供新的配对或报分规则。

#### Scenario: 套用与更新
- **WHEN** 创建者选择街霸六预设并在之后读取赛事，期间资源目录更新
- **THEN** 游戏身份保持街霸六，配置版本和冻结快照不因资源变更而改变，运行状态仍未开赛

#### Scenario: 统一影之诗与职业并列
- **WHEN** 用户选择影之诗预设并查看两个版本的资源
- **THEN** 始终使用同一shadowverse游戏ID，职业列表同时显示死灵、吸血鬼、梦魇，各有独立ID与图标；资源保留出处，不要求再次选择版别

### Requirement: GP2 素材种类与来源
系统 SHALL 为街霸六角色头像和立绘，以及影之诗卡片头像、插画和职业图标分别记录素材用途。每项资源具有稳定实体ID、游戏ID、原始名称、显示名、资料语言、版本、来源页面、素材状态及用途；可用图片还需已核实图片地址或本地引用、尺寸及分发依据。卡面不自动等于无背景立绘，职业图标不得用任意卡片代替。缺少可核实素材时明确missing或pending状态，不把官方网页伪装成稳定公共API，不声称覆盖全部角色或卡片。

#### Scenario: 跨来源卡片ID不冲突
- **WHEN** 原版与Worlds Beyond资源有相同原始卡片ID或名称
- **THEN** 使用来源版本与原始ID组成不同稳定实体ID，保留各自图片与出处，不覆盖卡片或拆成不同游戏预设

#### Scenario: 查看样例素材
- **WHEN** 用户查看游戏样例资源
- **THEN** 可区分角色头像/立绘、卡片头像/插画与职业图标，看到对应实体、版本与来源；名称是文本，资料不产生报名或角色报分记录

#### Scenario: 尚未取得立绘
- **WHEN** 已核实卡片页面但没有独立立绘文件
- **THEN** 可显示已核实卡面及文字，并明确立绘尚缺，不用卡面冒充已完成的立绘资源

### Requirement: GP3 资源读取失败与权限隔离
系统 SHALL 允许公开读取非敏感游戏目录和样例素材信息；素材图像加载具有加载、成功、失败/缺失状态、替代文本与重新尝试入口。图像403/404、超时或目录失败不清空当前赛事表单，不阻断已有赛事管理与提交，不泄露私有赛事。资源没有管理权限含义，不接受用户提交任意远程地址作为赛事所有权或可信素材。

#### Scenario: 图像失败
- **WHEN** 角色头像图片404或立绘被远端拒绝
- **THEN** 显示实体名称和素材不可用状态，可以重试；当前游戏选择、输入与已保存数据保持不变

#### Scenario: 目录请求失败
- **WHEN** 游戏目录暂时无法读取
- **THEN** 显示可恢复错误，已有赛事仍可查看且其旧字段不被覆盖；用户不必重新输入整张表单
