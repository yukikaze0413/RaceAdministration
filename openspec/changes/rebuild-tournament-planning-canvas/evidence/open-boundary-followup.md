# 2026-10-14 子图完整边界核验

问题：用户指出未勾选隐藏悬空输入时，子图仍缺输入接口。

根因：encapsulate只遍历已有跨界edges并增加终端W，未连接输入不生成boundary。单个无连线Match封装的测试先失败，实际input=[]，显示按钮默认false；因此是结构统计漏建而非显隐按钮默认开启。

修复：syncFreeBoundaries从内到外收集直接子节点的所有开放端口，内部已连接者不暴露，跨界边界和已有ID保留；按物理endpoint去重，collection附带seed映射去重。无连线Match默认A/B输入和W/L输出。预设包先清除自动边界再赋固定接口，转自定义后完整统计；旧auto字段保留值但不限制完整接口。

验证：29画布领域及HTTP测试通过；15真实Edge通过，新增单Match子图默认全部接口、输入/输出独立隐藏及恢复测试。原七场单败封装现在暴露7个未消费L加最终W，共8输出，内部W不重复暴露；计划与来源等价测试继续通过。构建通过，规格与差异检查通过。测试隔离库，未改真实业务数据。

另一个问题只作讨论：现有collection允许fan-out，单seat禁止多路消费。共享集合读取可行；真实人员分到两个同时比赛组需明确分流规则及身份重叠约束，当前连线不自动做不重叠分配。
