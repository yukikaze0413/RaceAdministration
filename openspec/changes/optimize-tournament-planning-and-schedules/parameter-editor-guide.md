# 赛制参数使用说明（任务1.3，2026-10-08）

在赛事管理的「概览与配置」点击「新建赛制配置」。选择赛制、人数、小组数量、每组晋级人数后查看总输入/总晋级摘要，再「创建阶段」。默认集来自服务器目录；目录失败时通过「重试」恢复，不使用猜测值。旧「新建空草稿」和现有v1编辑路径保留。

GSL默认4人×4组、每组2晋级，即16输入/8晋级。单败默认8人×1组、1晋级；双败默认8胜者输入×1组、1晋级；两类瑞士默认16人×1组、8晋级；单双循环默认4人×1组、2晋级。单败完整模式仅二次幂人数，高级分段模式允许符合N/Q比例的其他人数。小组数量受赛事总入口64人上限约束，调整联动数量时会提示重新确认摘要。

「高级赛制参数」只显示当前规则的参数：种子落位、按角色/轮次BO覆写、单败季军战、双败败者直接输入/决赛重置、瑞士轮数或胜败阈值/积分/排序、循环积分/排序。每组人数在双败表示胜者输入N；额外败者输入L由无/同等/一半派生，摘要统计N+L。Q>1不显示季军/决赛重置；N<4清除季军开关及其BO覆写。积分要求完整且胜>平≥负，非法高级参数禁止保存。

保存后刷新恢复服务器原值。增加组数保留原组ID；缩组或换赛制先展示消失小组、连线与报名/比赛影响，只有「确认并保存」才应用。Escape或「取消」关闭确认且保留当前输入；锁定名单/比赛的阻断不可强行确认。

出现409时本地输入保留。点击「读取最新版本」查看服务器和本地数量、高级参数差异；明确选择「保留我的输入，采用最新版本」后重新检查保存，或选择「使用服务器参数」替换输入。服务端已提交但响应丢失时直接「重试」，使用原请求键取回成功结果，不重复增版本。

阶段切换会询问是否放弃未保存输入。配置子页之间保留草稿；真正离开可保存、舍弃或继续编辑，失败保留输入。详见[配置草稿与离页说明](editor-session-guide.md)。v2完整比赛计划已可核验和冻结（任务3.1）；实际运行仍在接入，不代表可以开赛。旧v1草稿可显式复制升级，见[复制升级说明](copy-upgrade-guide.md)。

验收见[acceptance-parameters.md](acceptance-parameters.md)，详细规则见[parameters.md](parameters.md)。
