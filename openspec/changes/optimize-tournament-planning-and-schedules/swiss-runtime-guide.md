# 通用瑞士运行与裁定

swiss-fixed-v1打满冻结R轮后按公布排序取Q人；swiss-threshold-v1达到W胜晋级、L负淘汰，达阈值者不再出轮，最多W+L−1轮。这是平台通用版本，科隆2026及TI15的精确规则adapter仍等待专属证据与验收。

具名入口位置决定本阶段初始种子，身份和赛事原始种子仍保留在roster。首轮固定上半区对下半区。后续硬禁重赛，以完整匹配为先，固定瑞士最小化配对积分绝对差之和，阈值瑞士最小化胜数差与负数差的绝对值之和；等成本按种子顺序选择第一个完整匹配。轮空仅给未获满分轮空者，固定瑞士先选最低积分、同分最大种子号，并求剩余完整匹配；阈值按较低胜负差优先。轮空计胜及满胜积分，没有数字局比分和实际对手。

求解版本swiss-pairing-v1固定250000访问节点预算。证明无完整合法匹配显示无解；达到预算显示尚未证明无解。均不创建部分轮次。普通结果提交不能覆盖这些约束。管理员可在配对阻塞页逐场选择完整双方、合法轮空者并记录原因，保存复核输入版本及hash；不能重赛、复制身份、重复满分轮空或替换冻结首轮表。

固定瑞士默认积分3/1/0/0，排序积分→BH对手积分和→净胜局→阶段初始种子。BH为实际交手对手当前积分之和；阈值默认胜负战绩→DS对手胜负差→种子，DS为每次交手对手当前胜数减负数之和。双方负各加一负，保留实际对手，但净胜局贡献0；bye的BH/DS贡献0。页面可展开排序公式和每个对手的原始积分/战绩。手机表格可横向滚动，并支持键盘方向键。

积分及BH用精确整数累加；不超过安全整数范围返回number，超出返回规范十进制字符串。v2来源禁止小数和不安全numeric points，允许规范十进制整数字符串并准确排序；v1来源数值契约保留。Swiss的rankingProfileId/recordProfileId绑定冻结参数摘要，不把不同分制成绩混排。

未配置种子终键且切线同分，停在同分待裁定，不能晋级；管理员只能调整并列者并记录原因。阈值双方负造成实际晋级人数偏离固定配额时显示实际/要求数量，后续路由阻塞，不补造胜者。每轮BO来自冻结轮次/角色覆盖；晋级战与淘汰战同时触发时取两项较大值。

开赛、整轮确认、排名与人工配对的计算在SQLite事务外准备。应用事务内部再次复验当前权限、期望版本和完整输入摘要，再原子保存比赛/状态/成功请求键。缓存成功请求不重新求解已锁轮次，仍复核当前权限及请求指纹。公开视图去除裁定actorId、用户ID和报名答案。
