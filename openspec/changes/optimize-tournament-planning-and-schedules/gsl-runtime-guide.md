# 经典GSL实际运行

选择gsl-classic-v1，每组固定4人、2人出线。可建立多个独立组；默认4组，共16位参赛者与20场比赛。组内分三批次：两场首轮；胜者战及淘汰轮；一场出线战。每组独立确认，不要求其他组同时推进。

种子入口首轮1对4、2对3；绝对席位入口按相邻物理位置1对2、3对4。跨入口类型按递归种子表换算，组内不混用位置类型。使用冻结计划，首轮/胜者战/淘汰轮/出线战各可覆盖BO，已冻结参数不能运行中修改。

独立算例：首轮A胜D、B胜C，胜者战A胜B、淘汰轮C胜D、出线战B胜C，A/B依次出线，最终实际战绩A2胜0负、B2胜1负、C1胜2负、D0胜2负。页面显示有序出线，刷新仍保留全部五场及裁定。

必须裁定齐当前批次全部场次才确认；时间计划不改变批次。results.edit不能确认，rounds.confirm撤销后原成功键重放也拒绝。确认永久锁定赛果，并发至多一次推进，数据库异常整体回滚。
