# 独立演示空间

登录后打开“赛事示例”，选择暗影杯或两种 GSL 接双败配置，勾选确认并创建。进入后顶部持续显示“隔离演示空间”，可以返回原空间；原空间登录仍保留。刷新原入口后，可从“已创建的独立演示”重新打开原实例，已保存的配置、审批、比分和时间不会重置。

创建提供配置草稿和待审批的参考单位标签。通过现有页面编辑、冻结、逐个审批并分配种子/组/槽位，锁定名单后开赛。随后安排资源与窗口，逐轮录入比分并确认，使用赛制图、按轮次、按时间段查看。固定种子只用于独立验收比分，不自动录入成绩。暗影杯为 32 单位五轮瑞士接八强单败，共 87 场；GSL 四组接八人双败为 34 场，开启重置且败者方赢得第一场总决赛时增加一场，合计 35 场。

创建结果已提交但网络响应丢失时，重试使用同一请求键恢复原实例。即使示例目录后来升级，原键与原输入仍返回原结果；新建请求必须重新读取当前目录版本，同一键改变输入则冲突。每次重试仍先验证原账号的当前会话。

参考单位不是团队成员报名。演示使用独立 `.reference-demos/<实例ID>.sqlite` 和限定子空间路径的会话；原赛事目录、赛事行和成员数据不会被示例导入写入。演示账号由原空间管理，重新进入由原账号发放演示会话。原账号会话过期或撤销后，演示写操作也被拒绝。

注销原账号前，预览包含独立演示数量和当前状态。父数据库事务失败时，演示文件保留；父账号删除提交后才清理演示库及 WAL/SHM。文件暂时占用时保留持久清理记录并重试；重启和最后一个实例关闭后也继续清理。清理记录先写临时文件、刷盘、原子发布，避免中断写入生成半段 JSON。

科隆 2026 和 TI2026 当前显示待核验原因，不能创建或运行历史复现。三个通用模拟工程通过不等于两个真实赛事已通过，也不等于用户业务接受。
