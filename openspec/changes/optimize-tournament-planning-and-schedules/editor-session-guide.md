# 配置草稿与离页说明（2026-10-09）

参数、结构、节点位置在同一配置的子页面之间保留。切换参数、画布、选手池、路由、校验或来源预演无需先保存；不同赛事或配置、配置列表和其他页面属于真正离开。

有实际修改时，离开可选「继续编辑」「舍弃后离开」「保存后离开」。恢复原值后不再提醒。仅缩放或平移画布不算结构修改；在配置子页之间保留视角。节点位置属于布局草稿，与结构使用独立版本保存。初次读取布局完成前不能移动节点。

「保存后离开」先保存结构/参数，再保存布局，全部成功才离开。缩组等操作仍须明确确认影响；取消后留在配置。断网或保存失败保留输入并允许重试；409先读取比较，再明确保留本地或采用服务器版本。已经提交但响应丢失时使用原请求键重试。

刷新或关闭页面时，有实际未保存修改会触发浏览器提醒。浏览器原生提醒的文案由浏览器决定。草稿只在当前配置会话内保留，不承诺浏览器关闭后的本地持久化。

冻结前提供保存草稿后冻结或舍弃草稿冻结已保存版本。布局也需要处理；保存后的真实配置版本用于冻结。旧v1可按已有流程冻结。v2现在可冻结完整编译计划；实际运行器仍待后续任务，不把冻结当作开赛。见[编译计划契约](compiled-plan-api.md)。

高级参数中，缺失的枚举可以重新选择；「恢复默认排序」只恢复排序项，不覆盖BO等其他输入。固定轮数瑞士默认排序为积分、BH积分、净胜局、初始种子。

验收与证据见[acceptance-editor-session.md](acceptance-editor-session.md)。
