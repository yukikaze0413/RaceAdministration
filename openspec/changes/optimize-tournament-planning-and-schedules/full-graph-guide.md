# 完整比赛图与具名连接

配置的「赛制画布」先显示阶段小组与选手池总览。「查看比赛子图」进入一个小组的完整签表，返回阶段总览不会改比赛关系。单败显示所有胜者依赖，GSL显示五场三批次，双败区分胜者组、败者组、总决赛和条件重置赛。单/双循环按轮次列出全部对局，奇数休息不生成假比赛。瑞士只为已生成配对显示比赛；未来轮次保持待配对窗口。已运行且配置 ID 匹配时，真实身份、裁定及确认状态用相同 planKey 回填。

条件 GF2 在尚未激活时没有选手身份或比分。多人资格路由的未来来源显示范围和排序后席位，不猜某一个晋级者。瑞士新生成比赛保留配对前胜负/积分；旧运行数据缺少该字段时不回填当前战绩冒充历史战绩。

手机默认列表，可切换画布；列表保留完整来源文字。画布内部滚动、缩放及平移只影响查看，不触发离页提醒。节点标题支持拖动与方向键，每次移动20单位；节点勾选后可左/上对齐，小组总览支持反向排序，恢复自动布局只重置当前图节点。自动布局由结构确定，刷新可重现；64人单败逐对检查节点不重叠。

具名端口按钮与「连接来源出口」「连接目标入口」选择器共用同一选择状态。填写来源起止名额和目标位置序列，位置数须等于名额数；点击「校验并添加连接」先读取服务端只读校验报告，合法才加入草稿，再点击「保存结构草稿」。来源已分配范围不能一对多复制。目标冲突必须确认删除冲突的整条路由；取消不改草稿。双败有 upper/lower 独立通道，也可使用 qualification 汇总视图（upper第1名额，lower名额顺次接续），真实身份仍须复核。池输入没有端口字段，池输出使用seed。

布局独立保存，不更改结构版本或赛果。只保存已存在的阶段/小组/池/比赛/窗口引用，缩组删除消失节点，纯 BO 修改保留稳定比赛位置。无关连线草稿不完整时仍保留有效小组的布局，不把局部布局有效等同整套结构有效。布局409读取服务器版本后，明确选择保留本地位置或使用服务器布局；布局未保存即切参数页面后「保存后离开」也保存比赛子节点。

该页面是管理者结构画布。公众签表、时间窗口、资源与批量时间编排属于后续赛程模块，不能把本切片验收视为其已完成。
