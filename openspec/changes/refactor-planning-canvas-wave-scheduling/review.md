## 已修正

- 严格检查日历日期，拒绝自动归一化的非法日期。
- 同路径查询参数切换检查未保存草稿。
- 旧 batch 筛选加入项目身份。
- 排序预览拒绝失效 wave 引用。
- 预览拒绝旧算法版本的缓存。
- 预设复制重写条件比赛的内部引用。
- 产物保留图名称，赛程选择显示可读标签。

## 未采用的建议

session 数组不强制按开始时间重排。
数组表示用户创建的分组，不决定跨组执行顺序。
跨组顺序由依赖和时间检查确定。
比赛结果列表已经按日期排序。

主规格保留原场景名称“部分排序”。
该名称指映射只排序命中位置。
场景用 B/D 两个 key 明确范围。
保留名称避免改变已有验收引用。
