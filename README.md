# 赛事管理系统

面向卡牌和格斗游戏的赛事管理平台，当前处于需求澄清与 SDD 接入阶段。

## 已确认方向

- 赛事系列包含独立赛事，每场赛事可组合多个比赛阶段。
- 注册用户可创建和参加赛事，个人中心区分两个入口。
- 选手和主办方可提交赛果；主办方可修改并手动确认推进。
- 优先生成正确对阵；自动排时间与已推进后的回滚改判后置。
- 使用模拟赛事和正常、边界、异常样例验收。
